# Phase 2 Results Summary

All numbers come from `results/phase2/*.csv` (generated by `scripts/phase2_analysis.py`) and
`results/phase2/zero_model/` (E04). These are **full-scale** runs (1,200 series, 4 test origins x 28 days). They
were completed before rapid mode stopped the batch; they are not pilot results. Phase 1 numbers are from
`results/phase1/` (copy of `outputs/m5_main/report/`) and are labelled P1.

Cells: 1,116 warm series. "All days" = recorded sales (124,992 cells). "Non-censored" = days not in a
hindsight-flagged long zero run (114,127 cells), a proxy view of visible demand.

## Zero-run persistence model alone (E04, Brier of P(recorded zero))

LightGBM 0.1746; Kaplan-Meier renewal 0.1893; series zero rate 0.1915; masked DeepAR v2 0.1826; unmasked DeepAR v2
0.1754. LightGBM is significantly better than every non-learned baseline and masked DeepAR, and tied with
unmasked DeepAR. Removing explicit run features: no measurable change.

## Calibration

Randomised-PIT max deviation (0 = flat): hybrid 0.056-0.084, masked DeepAR v2 0.103-0.114, unmasked 0.050-0.079,
naive ZI 1.03. All DeepAR-based models over-cover the 80%/90% intervals (~0.93/0.96).

## Where it fails

For series in a zero run of >= 28 days at the origin (7.9% of series-origins): hybrid - DeepAR v2 pinball
-0.062 on all days and +0.064 on non-censored days. The hybrid forecasts recorded sales; masked DeepAR remains the
better latent-demand model for these series.

## Validated vs not validated

Validated: everything above, the 65 tests, exact Phase 1 reproduction. Not validated: the ablations listed as
stopped in `docs/PHASE2_RAPID_STATUS.md`; anything about real stockouts (no inventory data).
